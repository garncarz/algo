TWO EXAMPLES

Going deeper and returning

A recursive call pauses the current function.

Ready to call explore(0).

THE FUNCTION

Java-like pseudocode
void explore(int level) {
    if (level == 4) {
        print(indent(level) + "Rock bottom!");
        return;
    }
    print(indent(level) + "Entering deeper level...");
    explore(level + 1);
    print(indent(level) + "Return from deeper level.");
}

Recursion with return values

Calls go down first; each waiting call calculates on the way back up.

Ready to call factorial(4).

THE FUNCTION

Java-like pseudocode
int factorial(int n) {
    if (n == 1) {
        return 1;
    }
    return n * factorial(n - 1);
}
