Java Cheat Sheet

1. Variables and basic types

int count = 10;
long total = 1_000_000_000L;
double ratio = 3.14;
boolean ok = true;
char letter = 'a';
String word = "a";

'a' is a char; "a" is a String.

Java is statically typed. = assigns; == compares primitive values.

2. Arrays and strings

int[] a = new int[5];
int[] b = {2, 4, 6};

a[0] = 7;
a[1] = a[0] + 1;

String s = "hello";
char c = s.charAt(1); // 'e'

int lenA = a.length;
int lenS = s.length();

Indexing is zero-based. Arrays use a.length; strings use s.length().

3. Traversing arrays and strings

for (int i = 0; i < a.length; i++) {
    System.out.println(a[i]);
}

for (int value : a) {
    System.out.println(value);
}

for (int i = 0; i < s.length(); i++) {
    System.out.println(s.charAt(i));
}

Always use i < a.length, not i <= a.length.

4. Conditions and boolean operators

if (x == 0) {
    System.out.println("zero");
} else if (x < 0) {
    System.out.println("negative");
} else {
    System.out.println("positive");
}

if (a < b && b <= c || !done) {
    System.out.println("continue");
}

Compare with ==, !=, <, <=, >, >=.

= assigns a value; == checks equality.

5. Loops

for (int i = 0; i < 5; i++) {
    System.out.println(i);
}

int j = 0;
while (j < a.length) {
    System.out.println(a[j]);
    j++;
}

for (int i = a.length - 1; i >= 0; i--) {
    System.out.println(a[i]);
}

Loops need a condition that eventually becomes false. Make progress each time.

6. Methods, printing, and return values

void printHi() {
    System.out.println("Hi");
    return;
}

int doubleIt(int x) {
    return x * 2;
}

printHi();
int y = doubleIt(4); // 8

return; ends a void method. return value; returns a value to the caller.

7. Creating and filling arrays

int[] a = {1, 2, 3};
int[] result = new int[a.length];

for (int i = 0; i < a.length; i++) {
    result[i] = a[i] * 2;
}

Newly created int[] values start at zero.

8. Two-dimensional arrays

int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6}
};

int rows = matrix.length;
int cols = matrix[0].length;
int value = matrix[1][2];

for (int i = 0; i < matrix.length; i++) {
    for (int j = 0; j < matrix[i].length; j++) {
        System.out.println(matrix[i][j]);
    }
}

matrix.length = number of rows; matrix[i].length = columns in row i.

9. Useful arithmetic and character operations

int parity = n % 2;
int ones = n % 10;
int tens = n / 10;

int diff = 'c' - 'a'; // 2
int half = 7 / 2; // 3

n / 10 and n % 10 extract decimal digits. Integer division truncates fractional parts.

10. Creating objects and fields

class Node {
    int value;
    Node next;

    Node(int value) {
        this.value = value;
    }
}

Node a = new Node(10);
Node b = new Node(20);

System.out.println(a.value);
a.value = 15;

A class describes objects. new Node(10) creates an object; a.value accesses a field.

11. Object references and linking nodes

Node a = new Node(10);
Node b = new Node(20);

a.next = b;
b.next = null;

a.next = b stores a reference to the same object, not a copy. null means no linked object.

12. Basic trees

class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;

    TreeNode(int val) {
        this.val = val;
    }
}

TreeNode root = new TreeNode(1);
root.left = new TreeNode(2);
root.right = new TreeNode(3);
1root
2left
3right

left and right are references just like next in a linked list.

13. Basic graph representation

import java.util.*;

int n = 4;
List<List<Integer>> graph = new ArrayList<>();

for (int i = 0; i < n; i++) {
    graph.add(new ArrayList<>());
}

graph.get(0).add(1);
graph.get(1).add(0);
0 → [1]
1 → [0]
2 → []
3 → []

graph.get(u) is the neighbor list for vertex u. For directed edges, add one direction only.

14. HashSet — unique values

import java.util.HashSet;
import java.util.Set;

Set<Integer> seen = new HashSet<>();

seen.add(5);
seen.add(5);         // still one 5
seen.contains(5);     // true
seen.remove(5);
seen.isEmpty();      // true

A set stores unique values. Use it when checking whether a value has already been seen.

15. HashMap — key → value

import java.util.HashMap;
import java.util.Map;

Map<String, Integer> counts = new HashMap<>();

counts.put("apple", 2);
counts.get("apple");             // 2
counts.getOrDefault("pear", 0); // 0
counts.containsKey("apple");  // true
counts.remove("apple");

Map<Integer, Integer> freq = new HashMap<>();
for (int x : a) {
    freq.put(x, freq.getOrDefault(x, 0) + 1);
}

Maps store key-value associations. This pattern counts how often each integer appears.

16. Common mistakes and quick reminders

  • Use i < a.length, not i <= a.length.
  • Use s.charAt(i) for strings; s[i] is not valid Java.
  • Use a.length for arrays and s.length() for strings.
  • Use == for primitive comparisons; use = only for assignment.
  • Check whether a reference is null before dereferencing it.
  • Multiple variables may point to the same object.
  • HashSet stores unique values; HashMap stores key-value pairs.
  • Import classes from java.util.
