Java Cheat Sheet

1. Variables and basic types

int count = 10;
long total = 1_000_000_000L;
double ratio = 3.14;
boolean ok = true;
char letter = 'a';
String word = "a";

'a' is a char; "a" is a String.

Java is statically typed. = assigns; == compares primitive values.

2. Arrays and strings

int[] a = new int[5];
int[] b = {2, 4, 6};

a[0] = 7;
a[1] = a[0] + 1;

String s = "hello";
char c = s.charAt(1); // 'e'

int lenA = a.length;
int lenS = s.length();

Indexing is zero-based. Arrays use a.length; strings use s.length() and s.charAt(i), not s[i].

3. String manipulation

String s = "  Hello World  ";
s = s.trim(); // "Hello World"
boolean has = s.contains("Hello"); // true
String sub = s.substring(0, 5); // "Hello"
String[] words = s.split(" "); // 2 words

StringBuilder sb = new StringBuilder();
sb.append("Hello");
sb.append(" World");
String result = sb.toString();

Immutable: methods return new strings. trim() strips chars ≤ U+0020; modern strip() handles Unicode whitespace.

contains() is case-sensitive; substring(start, end) includes start, excludes end. split() takes a regex: " " is one space, "\\s+" a whitespace run; handle leading whitespace separately.

StringBuilder suits repeated appends, especially in loops; + is fine for simple concatenation.

4. Traversing arrays and strings

for (int i = 0; i < a.length; i++) {
    System.out.println(a[i]);
}

for (int value : a) {
    System.out.println(value);
}

for (int i = 0; i < s.length(); i++) {
    System.out.println(s.charAt(i));
}

Always use i < a.length, not i <= a.length.

5. Conditions and boolean operators

if (x == 0) {
    System.out.println("zero");
} else if (x < 0) {
    System.out.println("negative");
} else {
    System.out.println("positive");
}

if (a < b && b <= c || !done) {
    System.out.println("continue");
}

Compare with ==, !=, <, <=, >, >=.

= assigns a value; == checks equality.

6. Object comparison: == vs .equals()

import java.util.Arrays;

String s1 = new String("test");
String s2 = new String("test");
String value = null;
int[] a = {1, 2};
int[] b = {1, 2};

boolean sameObject = s1 == s2; // false
boolean sameText = s1.equals(s2); // true
boolean matches =
    "expected".equals(value);
boolean sameItems = Arrays.equals(a, b);

Primitive == compares values; reference == checks identity. .equals() follows the class implementation (string text); use it for strings.

"expected".equals(value) is null-safe; compare array elements with Arrays.equals(a, b).

7. Loops

for (int i = 0; i < 5; i++) {
    System.out.println(i);
}

int j = 0;
while (j < a.length) {
    System.out.println(a[j]);
    j++;
}

for (int i = a.length - 1; i >= 0; i--) {
    System.out.println(a[i]);
}

Loops need a condition that eventually becomes false. Make progress each time.

8. Methods, printing, and return values

void printHi() {
    System.out.println("Hi");
    return;
}

int doubleIt(int x) {
    return x * 2;
}

printHi();
int y = doubleIt(4); // 8

return; ends a void method. return value; returns a value to the caller.

9. Creating and filling arrays

int[] a = {1, 2, 3};
int[] result = new int[a.length];

for (int i = 0; i < a.length; i++) {
    result[i] = a[i] * 2;
}

Newly created int[] values start at zero.

10. Two-dimensional arrays

int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6}
};

int rows = matrix.length;
int cols = matrix[0].length;
int value = matrix[1][2];

for (int i = 0; i < matrix.length; i++) {
    for (int j = 0;
         j < matrix[i].length;
         j++) {
        System.out.println(matrix[i][j]);
    }
}

matrix.length = number of rows; matrix[i].length = columns in row i.

11. Useful arithmetic and character operations

int parity = n % 2;
int ones = n % 10;
int tens = n / 10;

int diff = 'c' - 'a'; // 2
int half = 7 / 2; // 3

n / 10 and n % 10 extract decimal digits. Integer division truncates fractional parts.

12. Creating objects and fields

class Node {
    int value;
    Node next;

    Node(int value) {
        this.value = value;
    }
}

Node a = new Node(10);
Node b = new Node(20);

System.out.println(a.value);
a.value = 15;

A class describes objects. new Node(10) creates an object; a.value accesses a field.

13. Object references and linking nodes

Node a = new Node(10);
Node b = new Node(20);

a.next = b;
b.next = null;

Node current = head;
while (current != null) {
    System.out.println(current.value);
    current = current.next;
}

a.next = b stores a reference to the same object, not a copy. null means no linked object.

Variables may alias the same node. Check for null before accessing fields; dereferencing it throws NullPointerException.

14. Basic trees

class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;

    TreeNode(int val) {
        this.val = val;
    }
}

TreeNode root = new TreeNode(1);
root.left = new TreeNode(2);
root.right = new TreeNode(3);
1root
2left
3right

left and right are references just like next in a linked list.

15. Basic graph representation

import java.util.*;

int n = 4;
List<List<Integer>> graph =
    new ArrayList<>();

for (int i = 0; i < n; i++) {
    graph.add(new ArrayList<>());
}

graph.get(0).add(1);
graph.get(1).add(0);
0 → [1]
1 → [0]
2 → []
3 → []

graph.get(u) is the neighbor list for vertex u. For directed edges, add one direction only.

16. HashSet — unique values

import java.util.HashSet;
import java.util.Set;

Set<Integer> seen = new HashSet<>();

seen.add(5);
seen.add(5);         // still one 5
seen.contains(5);     // true
seen.remove(5);
seen.isEmpty();      // true

A set stores unique values. Use it when checking whether a value has already been seen.

17. HashMap — key → value

import java.util.HashMap;
import java.util.Map;

Map<String,Integer> m = new HashMap<>();

m.put("apple", 2);
m.get("apple");             // 2
m.getOrDefault("pear", 0); // 0
m.containsKey("apple");  // true
m.remove("apple");

Map<Integer,Integer> freq = new HashMap<>();
for (int x : a) {
    int old = freq.getOrDefault(x, 0);
    freq.put(x, old + 1);
}

Maps store key-value associations. This pattern counts how often each integer appears.

18. Sorting arrays and lists

import java.util.Arrays;
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

int[] arr = {5, 2, 8};
Arrays.sort(arr); // {2, 5, 8}

List<Integer> list = new ArrayList<>();
list.addAll(List.of(5, 2, 8));
Collections.sort(list); // [2, 5, 8]

Both sort in place, in natural ascending order. List.of(...) requires Java 9+.

19. Queues and stacks with ArrayDeque

import java.util.ArrayDeque;
import java.util.Deque;

// Queue (FIFO)
Deque<Integer> queue = new ArrayDeque<>();
queue.offer(10);
queue.offer(20);
int first = queue.poll(); // 10

// Stack (LIFO)
Deque<Integer> stack = new ArrayDeque<>();
stack.push(10);
stack.push(20);
int last = stack.pop(); // 20

Queue: FIFO; stack: LIFO. offer() adds to the queue end; poll() removes the first item or returns null if empty.

push() adds to the stack top; pop() removes it or throws if empty. ArrayDeque rejects null; queues suit BFS, stacks DFS.
